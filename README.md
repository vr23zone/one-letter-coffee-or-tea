An entry for make.fun's ["One Letter: Coffee or Tea"](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) bounty.

The program writes exactly one letter — **A** (for coffee) — to `/output/entry.txt`,
with no trailing newline, no word, no explanation and no punctuation. Just `A`.
